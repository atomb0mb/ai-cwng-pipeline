# Prompts

Save the prompts you actually sent to your AI assistant, one file per step:

```
prompts/week-01/step-0-plan.md
prompts/week-01/step-1-parse.md
...
```

Each file should contain:
1. **The prompt, verbatim.** If you edited it after a bad first attempt, keep both versions and note what you changed.
2. **What came back,** in one or two sentences.
3. **What you'd change next time.**

**Why bother?** Prompts are the new source code. Comparing your week 1 prompts with your week 8 ones is the clearest measure of what you learned, and other learners can study them.

Before committing, remove anything personal: local paths, emails, internal names, credentials.
